                Cấu Hình Biến Môi Trường Render (Environment Variables)
              

            

            

              

                
PORT

                
Mặc định Render cấp tự động: 10000. Mã nguồn đã được cấu hình tự động nhận diện cổng từ $PORT.

              


              

                
SELLER_ACCESS_KEY

                
Mã khóa đăng nhập admin (Mặc định: thai). Bạn có thể đổi thành mật khẩu tùy thích trong Render Env.

              


              

                
DB_PATH

                
Đường dẫn cơ sở dữ liệu SQLite. Nếu dùng Render Persistent Disk, đặt: /var/data/cyberauth.db để giữ dữ liệu vĩnh viễn không bị mất khi deploy lại!

1. Bước 1: Deploy lên Render

      
Hệ thống đã có sẵn render.yaml, Procfile và requirements.txt. Chỉ cần đẩy code lên GitHub rồi chọn New + → Web Service hoặc Blueprint trên Render.

            Loại
            Tên Host
            Giá Trị Trỏ Về
          

        
        
          

            CNAME
            auth (hoặc subdomain bạn thích)
            <tên-app-render>.onrender.com
          

          

            A Record
            @ (nếu dùng tên miền gốc)
            216.24.57.1
          

        
      


      
3. Bước 3: Thêm Tên Miền Trên Render Dashboard

      
Vào Render → Chọn Web Service của bạn → Settings → Custom Domains → Bấm Add Custom Domain → Nhập tên miền (VD: auth.tenmienban.com). Render sẽ tự động cấp SSL HTTPS miễn phí.
